# FLAC → WAV для диджеев

Нужны WAV-копии FLAC-треков для твоего DJ-сетапа? Конвертируй FLAC из папки за один запуск на Windows — результат появится в отдельной папке `wav`.

**[Скачать BAT-версию для Windows — ZIP](https://github.com/Fsas12/flac-to-wav-dj/archive/refs/heads/main.zip)** · [English](README.md)

Бесплатно. Исходные FLAC остаются на месте, аудио обрабатывается на твоём компьютере.

**Что нужно:** Windows 10/11 и отдельно скачанный FFmpeg. Этой BAT-версии дополнительный PowerShell-скрипт не нужен.

**О релизе v1.0.0:** это другой вариант, основанный на PowerShell. Для него поступило сообщение о проблеме с запуском. По ссылке выше скачивается простой BAT-вариант, который сейчас рекомендуется в этой инструкции.

<a id="как-запустить"></a>

## Первый запуск

1. Скачай и распакуй ZIP по ссылке выше. Открой распакованную папку проекта с файлом `convert_flac_to_wav.bat`.
2. Подготовь FFmpeg. Для 64-разрядной Windows открой [сборки Gyan](https://www.gyan.dev/ffmpeg/builds/), скачай `ffmpeg-release-essentials.zip` и распакуй его. Из папки `bin` скопируй `ffmpeg.exe` к BAT-файлу. Если FFmpeg уже доступен через PATH, пропусти этот шаг.
3. Для первой пробы скопируй 1–2 FLAC-трека непосредственно в эту же папку. Вложенные папки не обрабатываются.
4. Дважды кликни `convert_flac_to_wav.bat`. В окне появятся ход обработки и сообщения FFmpeg.
5. Открой папку `wav` рядом с BAT-файлом. Прослушай результат и проверь WAV в своём DJ-софте или плеере перед обработкой всей подборки.

**Если WAV с таким именем уже есть, FFmpeg может спросить о перезаписи. Выбери `N`, чтобы сохранить его, или используй новую папку проекта для повторной конвертации. Автоматического пропуска существующих WAV в этом BAT нет.**

## Что умеет этот BAT

- Запускает FFmpeg для каждого файла `.flac` непосредственно в текущей папке.
- Сохраняет WAV с теми же базовыми именами в подпапку `wav`.
- Оставляет исходные FLAC без изменений.
- Показывает сообщения FFmpeg и оставляет окно открытым после обработки.
- Обрабатывает аудио локально: в BAT нет команд загрузки файлов в интернет или сбора телеметрии.

В этом простом варианте нет интерфейса настроек, обработки вложенных папок, автоматического безопасного пропуска WAV, CSV-логов и итогового счётчика готовых, пропущенных и ошибочных файлов.

## Звук и совместимость

BAT использует стандартные настройки конвертации FFmpeg в WAV. Стандартный аудиокодек WAV в FFmpeg — PCM 16 бит; выбора 24 бит или частоты дискретизации в этом BAT нет. Для 24-битного FLAC сохранение исходной разрядности не предполагается.

Совместимость зависит от частоты, разрядности и количества каналов, поддерживаемых твоим плеером. Проверь результат на нужном устройстве. Сохранение обложек и всех данных DJ-библиотеки не гарантируется. WAV обычно занимает больше места, чем FLAC.

Утилита не форматирует флешку и не анализирует треки в DJ-софте.

## Если не работает

**FFmpeg не распознаётся как команда:** положи `ffmpeg.exe` в распакованную папку проекта и запускай BAT из этой папки. Другой вариант — добавить папку `bin` FFmpeg в PATH и перед повторной попыткой открыть новый терминал.

**FLAC не конвертируются:** положи треки непосредственно рядом с BAT. Файлы во вложенных папках не обрабатываются.

**FFmpeg спрашивает о перезаписи:** выбери `N`, чтобы сохранить существующий WAV. Для повторной конвертации используй другую папку проекта.

**Появилась ошибка или WAV не воспроизводится:** прочитай сообщение FFmpeg в окне и проверь, воспроизводится ли исходный FLAC. Этот BAT не проверяет готовые файлы и не создаёт CSV-отчёт об ошибках; проверь результат перед использованием в сете.

**Ты скачал v1.0.0:** этот релиз использует другой вариант на PowerShell. Для простого BAT-сценария из этой инструкции скачай ZIP по ссылке в начале страницы.
